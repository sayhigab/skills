# Nome amigável da skill

Objetivo em duas ou três frases: o que é um bom resultado e por que ele importa.

## 1. Primeiro passo

Explique o que fazer e o porquê. A IA segue melhor quando entende o motivo do que quando recebe ordens soltas.

## 2. Segundo passo

Se houver um script em `scripts/`, diga quando rodar e o que fazer com a saída:

```bash
node scripts/exemplo.mjs <entrada>
```

## Entrega

Diga o formato do resultado. Um modelo curto ajuda:

```
## Resultado
- …
```
